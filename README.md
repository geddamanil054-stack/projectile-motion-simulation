# Projectile Motion Simulation

This project simulates projectile motion using Python.

## Overview
The program calculates:
- Time of Flight
- Maximum Height
- Range of the projectile

## Concepts Used
- Mathematical Modelling
- Physics-based trajectory equations
- Python math library

## Relevance
This project demonstrates basic simulation modelling concepts relevant to aerospace and computational applications.

## How to Run
1. Install Python
2. Run: python projectile.py
3. Enter velocity and angle values
